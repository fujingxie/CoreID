CoreID 后台侧边栏使用说明

这份文档专门对应后台左侧栏。每一项都说明“点进去是什么页面、能做什么、具体怎么操作、哪些能力已经可用、哪些还只是占位”。 如果你要培训运营或交接后台，这份文档会比通用说明更直接。

后台入口：http://localhost:3000/admin 说明对象：左侧栏所有菜单 状态说明：已可用 / 部分可用 / 占位

菜单目录

1. 怎么看这份文档 2. 概览 Dashboard 3. 用户管理 4. 购买记录 5. 应用管理 6. 落地页管理 7. 安装包管理 8. 增长分析 9. 消息推送 10. 套餐配置 11. 权限管理 12. 审计日志

1. 怎么看这份文档

状态 说明
已可用 这项功能已经能在后台直接操作，并且主闭环已走通。
部分可用 能看、能做一部分操作，但还有增强项或边缘能力没完全补齐。
占位 侧边栏里有入口，但当前还没有真正页面逻辑，或只是预留模块。

建议你在后台对照左侧栏一项项点，这样最容易把文档和实际界面对应起来。

2. 概览 Dashboard

已可用

这是后台首页，主要是看平台整体运行情况，不负责具体编辑操作。

点进去能看到什么

  • 总用户数、今日新增、总收入、活跃设备数
  • 用户增长趋势图
  • 产品用户分布
  • 收入构成
  • 最近动态

怎么用

1

先看平台健康度

每天先看总用户、收入、活跃设备有没有异常波动。

2

看应用分布

确认 VidGet、助教云等应用的用户占比有没有变化。

3

看最近动态

快速了解注册、购买、发布等最近发生的关键事件。

3. 用户管理

已可用

这是最核心的运营页之一，用来查用户、看资格、看设备、看购买、改账号状态。

点进去能做什么

  • 搜索手机号、用户名、邮箱
  • 按购买状态筛选：已购买、已过期、免费用户
  • 按应用筛选：只看某个应用的用户
  • 按注册时间筛选：今天 / 近 7 天 / 近 30 天
  • 导出用户 CSV
  • 添加用户并补开某个应用资格
  • 打开用户详情抽屉，查看概况 / 购买记录 / 登录设备 / 操作日志

用户详情里怎么用

1

看应用资格

确认用户拥有哪些应用的注册资格，能不能登录某个应用。

2

看设备状态

区分当前有效设备和历史失效设备，排查顶号或单设备限制问题。

3

做账号操作

可以保存资料、重置密码、停用账号、恢复账号。

4

看真实事件流

注册、登录、资格变更、购买行为都会进入用户事件流。

4. 购买记录

已可用

这个页面主要管订单和支付状态，不是套餐配置页。

点进去能做什么

  • 查看订单列表、今日收入、客单价、退款金额
  • 按关键词搜索订单号或手机号
  • 导出订单数据
  • 打开订单详情弹层
  • 在订单详情里做状态流转：标记支付成功 / 失败 / 退款 / 过期
  • 查看订单事件流和支付回调结果

推荐操作

1

先查订单状态

搜索订单号，确认是 pending、paid 还是其他状态。

2

打开订单详情

看订单事件流和支付确认时间，判断是不是支付回调没到或状态流转错误。

3

必要时手动修正状态

后台可手动改订单状态，但会写入审计日志和订单事件流。

5. 应用管理

已可用

这是平台级应用清单，不是某个应用的业务后台。

点进去能做什么

  • 查看应用卡片和基础统计
  • 接入新应用
  • 编辑应用名称、描述、类型、状态
  • 查看 SDK 文档
  • 导出 SDK 文档 Markdown
  • 从应用卡片跳转到该应用的用户、落地页、安装包上下文

怎么接入一个新应用

1

点“+ 接入新应用”

填写 App ID、应用名称、应用类型、状态和描述。

2

保存后继续配套

应用创建后，再去套餐配置、落地页管理、安装包管理补齐能力。

3

导出 SDK 文档

接入方需要 Android 或 Web 文档时，从这里打开并导出 Markdown。

6. 落地页管理

已可用

这个页面是做下载页、投放页和活动落地页管理的，不是内容 CMS。

点进去能做什么

  • 新建落地页草稿
  • 上传 HTML 草稿
  • 预览草稿
  • 正式发布
  • 下线
  • 查看历史版本并回滚

正确操作顺序

1

先新建草稿

通过“+ 新建落地页”为应用生成默认草稿模板。

2

上传或编辑 HTML

当前上传的是草稿，不会直接改线上页。

3

先预览草稿

确认下载按钮、二维码和视觉样式没问题。

4

再发布

发布后线上公开页才会切换到新版本。

7. 安装包管理

已可用

这里负责应用分发，不只是上传文件，还包括版本历史、统计和二维码。

点进去能做什么

  • 上传 APK / EXE / DMG 文件
  • 配置 Web / App Store 下载链接
  • 查看当前版本和历史版本
  • 回滚历史版本
  • 删除当前版本
  • 删除整个版本历史
  • 查看下载统计
  • 生成下载二维码

推荐操作顺序

1

点“+ 上传安装包”

选择应用、平台、版本号，然后上传文件或填写 URL。

2

检查当前版本

上传后列表会显示当前版本、大小、平台、更新时间。

3

看历史和回滚

如果线上版本有问题，直接回滚到上一个版本。

4

看二维码和统计

用二维码给外部用户扫码下载，用下载统计看版本分发效果。

8. 增长分析

占位

当前侧边栏里有这个入口，但还没有真正的页面和操作逻辑。它更像未来要补的运营分析模块。

未来大概率会承担什么

  • 渠道新增分析
  • 注册转化率
  • 购买转化漏斗
  • 不同应用的增长趋势拆解

9. 消息推送

占位

当前也是预留入口，还没有正式页面。以后会更像“通知中心”，而不是聊天功能。

未来可能做什么

  • 套餐到期提醒
  • 支付成功通知
  • 新设备登录提醒
  • 按应用群发运营消息

10. 套餐配置

已可用

这里是“卖什么、卖多少钱、卖多久”的配置页，不是订单页。

点进去能做什么

  • 按应用筛选套餐
  • 创建新套餐
  • 编辑套餐名称、编码、价格、时长
  • 设置试用套餐 / 支持续费
  • 查看购买次数

怎么新建套餐

1

先选应用

套餐一定是属于某个应用的，不是全平台通用。

2

选套餐编码和名称

后台已有预设值，适合月付、季度、年度、试用等常见类型。

3

填价格和有效期

比如月付 30 天、年付 365 天、终身版可留空有效期。

4

决定是否试用 / 可续费

试用套餐和可续费会影响购买预校验和订单逻辑。

11. 权限管理

占位

目前没有正式页面逻辑。现在后台管理员权限主要还是通过 Casdoor 管理员身份 + 本地后台会话控制。

未来可能承担的内容

  • 平台管理员角色拆分
  • 运营 / 客服 / 财务权限隔离
  • 只读权限和操作权限区分

12. 审计日志

已可用

这是后台操作留痕页，用来查管理员做过什么，不是用户行为页。

点进去能做什么

  • 看操作时间、操作类型、操作者、对象、详情
  • 按对象类型筛选：安装包、落地页等
  • 按操作者搜索
  • 刷新查看最新日志

适合什么场景

  • 查是谁上传了某个安装包
  • 查是谁回滚了落地页
  • 查谁手动改了订单状态
